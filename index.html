Giới hạn kết nối

Bookmarklet chỉ đọc văn bản DOM mà trang cho phép hiển thị. Nếu trò chơi vẽ kết quả bằng canvas, WebGL, ảnh hoặc dữ liệu mã hóa, công cụ có thể không đọc được. Khi đó cần nhập dữ liệu thủ công hoặc dùng ảnh/OCR. Cơ chế này không lấy cookie, không đọc mật khẩu, không tự đặt cược và không vượt cơ chế bảo vệ của LC79.

Cách chạy website

  1. Cài Python 3.10 trở lên.
  2. Giải nén gói dự án.
  3. Mở Terminal tại thư mục dự án và chạy pip install -r requirements.txt.
  4. Chạy uvicorn lc79_api:app --host 127.0.0.1 --port 8000.
  5. Mở http://127.0.0.1:8000.

Để mở từ iPhone, máy tính và iPhone cần cùng mạng Wi-Fi; chạy server với --host 0.0.0.0, sau đó truy cập IP nội bộ của máy tính và cổng 8000. Muốn website công khai cần triển khai lên máy chủ HTTPS.

API docs

Khi server đang chạy, mở /docs để xem và thử toàn bộ endpoint FastAPI.
